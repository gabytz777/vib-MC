Quick start

Grab Java 11 or newer, build, and run. The server listens on port 25565 and does its best.

$ gradle build

$ java -jar build/libs/vib-mc.jar

[vib-mc] starting server on 25565...

[vib-mc] terrain generating... somewhere.

[vib-mc] camera status: believes it is moving.

Commands

Twelve slash commands. Enough to admin a server, barely enough to play one.

players /tp /gamemode /give /kill /list
world + admin /time /weather /seed /say /save-all /stop /help

Architecture

Nine packages, each doing one job with various amounts of confidence.

net.vibmc
|-- server   makes it go
|-- network  talks to minecraft
|-- world     blocks and stuff
|-- world.gen makes the ground
|-- entity   things that move
|-- player   the people
|-- plugin   mod support
|-- command  slash commands
`-- permission who can do what

  • plugin system

    Real events (join, quit, chat, tick), cancellation, priorities, and a loader. Written like the server actually needs it, because it does.

  • network stack

    Handshake, login, status, and play handlers speaking protocol 340. The part that makes real Minecraft clients say hello.

  • world pipeline

    Chunks generate, get patched, and stream out to clients. The rendering side is where the vibes currently lose.
